# 🏙️ Smart Civic Complaint Management System

A full-stack civic-tech web application that enables users to report civic issues such as road damage, garbage, and water leakage, along with supporting images and location information. The system generates a unique complaint ID, allows users to track complaint status, and provides an admin dashboard for managing submitted complaints.

---

## 📌 Project Overview

KuralKodu is a full-stack civic complaint management system designed to help users report common civic issues and track their complaints.

The application connects a frontend interface with a Node.js and Express.js backend and uses MongoDB for storing complaint data.

### The project includes:

- Civic complaint submission
- Image upload for complaints
- Automatic location detection
- Unique complaint ID generation
- Complaint status tracking
- Admin dashboard for complaint management
- Real-time status updates

---

## 🚀 Features

### User Features

- Submit civic complaints with descriptions
- Upload images related to reported issues
- Automatically capture the user's location
- Receive a unique complaint ID
- Track submitted complaints
- View complaint status updates

### Admin Features

- View submitted complaints through an admin dashboard
- Review complaint details and uploaded images
- Update complaint status
- Manage reported civic issues
